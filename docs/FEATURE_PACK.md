# CareCompass AI — Feature Pack (Standout USPs)

## Core (P1)
1. Hinglish-first voice intake (Web Speech API + fallback)
2. Safety-first triage (dual-layer red-flag bypass)
3. Unified care routing (one engine → matching)
4. Dynamic caregiver ranking (skills, availability, distance, language)
5. Explainable recommendations (per-caregiver reason)
6. Adaptive follow-up (one question at a time)
7. Fallback + booking workflow
8. Family-assisted mode (consent + proxy)
9. Multi-symptom context-aware routing
10. Elderly/low-literacy accessible UX
11. Privacy-by-design & minimal data
12. Measurable safety & transparent performance

## Differentiators (P2)
- Affordability-aware options
- Structured consented handover summary
- Post-booking follow-through (reminders, worsening escalation)
- Low-bandwidth/interrupted-network resilience (PWA shell)

## TinyFish Integration
- Search: clinical grounding snippets
- Fetch: clean protocol ingestion
- Agent: live credential verification (NMC/State Councils)

## Privacy & Security
- Zero-PII hashing, ephemeral sessions, data minimization
- Input sanitization + prompt-injection defense
- Rate limiting 100/min/IP
- Audit trail with REQ- IDs
- Emergency invariant: safety over efficiency
